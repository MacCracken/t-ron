# Audit — 2026-11-03 (2.2.3 P(-1) sweep)

**Scope:** t-ron 2.2.2, all 19 `src/` modules (4,786 lines at the start),
as built against cyrius 6.7.18, libro 2.11.3, bote-core 3.8.1 and sigil
3.13.15. The first audit since 2.0.0's
([2026-04-14](2026-04-14.md)).

**Goal:** CLAUDE.md's P(-1) process: performance, memory, security and
edge cases, then repair, tests from the findings, post-audit benchmarks,
and the documentation audit.

## Method

1. **Baseline**: all suites (426 assertions), the cleanliness check, and a
   `bench-history.csv` row.
2. **Four independent read-only reviews**, one per module group: the
   request pipeline (`tron`, `gate`, `policy`, `rate`, `middleware`,
   `error`, `score`, `query`); detection (`scanner`, `pattern`,
   `correlation`, `llm_scan`); audit, crypto and OS I/O (`audit`,
   `signing`, `crypto_chacha20`, `signal`, `tools`); the safety submodule.
   Each finding came with a concrete trigger, confirmed by tracing the code
   or by a probe program.
3. **Re-verification** before repair: the probes were re-run, not taken on
   report.
4. **Repair by file ownership**: pipeline, audit, crypto and I/O by the
   maintainer's session; safety and detection by two parallel agents with
   explicit fix and defer lists.
5. **Every fix carries a regression test.** Each new test group was run
   against the 2.2.2 sources: it fails there (or the old code crashes), or
   it is a "stays clean" check guarding a false positive. Exceptions are
   named below.

fixed.** Three are deferred outright (D11, C8, C9), one is mitigated (C7)
and one documented (K5); seven fixes leave a named remainder deferred

## Behaviour changes callers will see

- **Signed mode.** After `tron_verify_and_load_policy`, `tron_load_policy`
  and `tron_load_policy_file` return `TRON_ERR_SIGNATURE`.
- **Strict policy loader.** Files the old parser tolerated may now be
  refused. A file with no `[agent."…"]` section is refused.
- **Identifiers** containing `"` or `\` are denied.
- **`DA_FLAG`** calls are now rate-limited and scanned; an unknown
  `DefaultAction` denies.
- **Safety**: `rm`/`dd` are matched anywhere in a command (`echo rm -rf /`
  blocks); a relative file path is blocked by any scope rule;
  `dd if=/dev/zero of=disk.img` is no longer blocked; an engine with no
  enabled policy blocks.
- **Scanner false positives** (known trade-offs of the rules added): a
  multi-line argument with a line starting with a shell command name, and
  `{{ a ~ b }}` / `{{a}}. {{b}}` template spans.
- **`llm_scanner_scan`** returns a `(status, value)` pair (`LlmScanStatus`);
  it had no callers.
